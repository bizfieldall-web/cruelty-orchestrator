# 출력 포맷 스펙

## 공통 원칙

- **쇼츠가 기준점**: 모든 포맷은 쇼츠의 핵심 메시지에서 출발
- **동일 주제, 다른 깊이**: 같은 날 같은 주제로 3개 포맷 생성
- **롱폼은 주간 종합**: 7일치 쇼츠를 관통하는 메타 분석

---

## 1. 쇼츠 (Shorts)

### 용도
유튜브 쇼츠 — 영상 대본 (매일 발행)

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 300-400자 |
| 영상 길이 | 60초 미만 (최대 3분) |
| 톤 | 분석적, 냉소적, 드라마틱 대비, 권위 있는 화자 |
| 구조 | Hook → Crisis → Turning Point → Result & Insight |

### 구조 상세 (4단계)
```
[Hook] 상식을 뒤집는 한 문장
  예: "매출 0원을 2년 버틴 미친 남자가 있습니다."

[Crisis - Dirty Origin] 가장 바닥을 기던 순간의 묘사
  창업자의 결핍, 콤플렉스, 처절했던 초기 상황

[Turning Point - Cold Pivot] 결정적이고 독한 선택
  생존을 위해 내린 비상식적/잔인한 결정

[Result & Insight] 반전된 현재 + 시청자를 향한 질문
  뼈를 때리는 한 줄 ("당신은 ~할 수 있습니까?")
```

### 작성 규칙
- "대단하다" 칭찬 금물 → "지독하다", "집요하다", "오만하다" 사용
- 숫자와 상황의 대비 극대화 (통장 잔고 0원 vs 기업가치 9조 원)
- 단순 기업 연혁 나열 금지
- "열심히 하면 성공한다" 식의 뻔한 교훈 금지
- 창업자의 '운'이 아닌 **'선택'과 '고통'**에 집중
- 초반 3초 후킹 필수

## 2. 블로그 (Blog)

### 용도
네이버 블로그 / 티스토리 — SEO 최적화 글

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | 정보 전달형, 친근하되 신뢰감 |
| 구조 | 제목 → 도입 → H2 섹션 2-3개 → 정리 → CTA |

### 구조 상세
```
[제목] 검색 키워드 포함, 궁금증 유발 (30자 이내)
[도입] 쇼츠 훅을 확장한 문제 제기 (2-3문장)
[섹션1] 배경/맥락 설명
[섹션2] 핵심 인사이트 (쇼츠 본론의 확장)
[섹션3] 실용적 시사점 / 적용 방법 (선택)
[정리] 핵심 3줄 요약
[CTA] 관련 글 링크, 구독 유도
```

### 작성 규칙
- 제목에 핵심 키워드 필수 포함
- H2 소제목으로 스캔 가능한 구조
- 쇼츠에서 다루지 못한 배경/맥락을 보충
- 출처/수치를 본문에 자연스럽게 포함
- 이미지 삽입 위치 표시: `[이미지: 설명]`

## 3. 브런치 (Brunch)

### 용도
브런치스토리 — 에세이/칼럼형 글

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | 에세이, 사색적, 개인 관점 강조 |
| 구조 | 제목 → 도입(경험/관찰) → 전개 → 인사이트 → 여운 |

### 구조 상세
```
[제목] 문학적/감성적 표현 (호기심 유발)
[도입] 개인 경험이나 관찰에서 시작 (3-4문장)
[전개] 주제를 깊이 있게 풀어가는 서사 (쇼츠 핵심을 '이야기'로)
[인사이트] 독자에게 전하고 싶은 한 가지 메시지
[여운] 질문 또는 열린 결말로 마무리
```

### 작성 규칙
- 블로그와 달리 **개인 시점(1인칭)** 활용
- "나는 ~라고 생각한다", "~를 보면서 느낀 건" 등
- SEO보다 **읽는 맛**에 집중
- 데이터를 직접 나열하지 않고 이야기 속에 녹여내기
- 문단 사이 호흡 (한 문단 3-4문장)

## 4. 롱폼 (Long-form) — 주간 종합

### 용도
유튜브 롱폼 영상 대본 — Weekly Wrap-up (차주 월요일 발행)

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 5,000-8,000자 |
| 영상 길이 | 8분 내외 |
| 톤 | 분석적, 냉소적, 권위 있는 연구소 화자 |
| 주기 | 주 1회 — 차주 월요일 (7일치 쇼츠 기반) |
| 구조 | Intro → Body (교차 편집) → Conclusion |

### 구조 상세 (3단계)
```
[Intro] 7개 기업이 서로 달라 보이지만 사실은 [하나의 공통점]이 있음을 선언
  주제 예시: 오만, 결핍, 생존 본능 등
  훅 포함 — 시청자의 호기심을 잡는 도발적 선언

[Body] 요일별 사례를 교차 편집하여 주제를 증명
  - 월~일 7개 쇼츠의 기업을 공통 주제로 엮음
  - 같은 카테고리 내 차이점 비교 분석
  - 각 쇼츠를 참조할 때 날짜/기업명 명시

[Conclusion] 기업의 흥망성쇠를 통해 배우는 인간 경영의 본질적 교훈
  - 뼈를 때리는 최종 인사이트
  - 시청자를 향한 철학적 질문으로 마무리
```

### 작성 규칙
- 7일치 쇼츠 대본을 모두 입력으로 받음
- 단순 나열이 아닌 **관통하는 하나의 거대한 주제(Pattern)** 도출
- "대단하다" 금물 → "지독하다", "집요하다", "오만하다"
- 창업자의 '운'이 아닌 **'선택'과 '고통'**에 집중
- 차트/비교표 삽입 위치 표시: `[차트: 설명]`

---

## 포맷 간 관계도

```
[매일]  쇼츠 ──→ 블로그 (같은 주제, 정보 확장)
          │
          └──→ 브런치 (같은 주제, 에세이 전환)

[주간]  쇼츠 7개 ──→ 롱폼 (종합 분석)
```

## 포맷별 핵심 차별점 요약

| | 쇼츠 | 블로그 | 브런치 | 롱폼 |
|---|---|---|---|---|
| **글자수** | 300-400자 | 1,500-2,500자 | 1,500-2,500자 | 5,000-8,000자 |
| **목적** | 후킹/충격/질문 | 정보 전달 | 공감/사색 | 주간 패턴 분석 |
| **시점** | 연구소(3인칭) | 연구소(3인칭) | 1인칭/주관 | 연구소(전문가) |
| **구조** | Hook→Crisis→Pivot→Insight | H2 섹션형 | 서사형 | Intro→Body(교차편집)→Conclusion |
| **독자 행동** | 영상 시청 | 검색→읽기 | 구독→읽기 | 깊이 몰입 |
| **SEO** | 해시태그 | 키워드 최적화 | 낮음 | 중간 |
| **주기** | 매일 | 매일 | 매일 | 주 1회 (월요일) |
