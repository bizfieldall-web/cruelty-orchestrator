# 출력 포맷 스펙

## 공통 원칙

- **쇼츠가 기준점**: 모든 포맷은 쇼츠의 핵심 메시지에서 출발
- **동일 주제, 다른 깊이**: 같은 날 같은 주제로 3개 포맷 생성
- **롱폼은 주간 종합**: 7일치 쇼츠를 관통하는 메타 분석

---

## 1. 쇼츠 (Shorts)

### 용도
유튜브 쇼츠 / 틱톡 / 인스타그램 릴스 — 영상 대본

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 500-600자 |
| 영상 길이 | 50-60초 |
| 톤 | 직설적, 임팩트, 구어체 |
| 구조 | 훅(3초) → 문제 제기 → 핵심 인사이트 → CTA |

### 구조 상세
```
[훅] 시선을 잡는 첫 문장 (충격/질문/반전)
[문제] 왜 이게 중요한지 1-2문장
[본론] 핵심 인사이트 3-4문장
[CTA] 구독/좋아요/다음편 예고
```

### 작성 규칙
- 한 문장 = 한 호흡 (15자 이내 권장)
- 전문 용어 사용 시 즉시 풀어서 설명
- 숫자/데이터로 구체성 확보
- 마지막에 "다음 쇼츠에서 더 깊이 다룰게요" 등의 시리즈 연결

## 2. 블로그 (Blog)

### 용도
네이버 블로그 / 티스토리 — SEO 최적화 글

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | 정보 전달형, 친근하되 신뢰감 |
| 구조 | 제목 → 도입 → H2 섹션 2-3개 → 정리 → CTA |

### 구조 상세
```
[제목] 검색 키워드 포함, 궁금증 유발 (30자 이내)
[도입] 쇼츠 훅을 확장한 문제 제기 (2-3문장)
[섹션1] 배경/맥락 설명
[섹션2] 핵심 인사이트 (쇼츠 본론의 확장)
[섹션3] 실용적 시사점 / 적용 방법 (선택)
[정리] 핵심 3줄 요약
[CTA] 관련 글 링크, 구독 유도
```

### 작성 규칙
- 제목에 핵심 키워드 필수 포함
- H2 소제목으로 스캔 가능한 구조
- 쇼츠에서 다루지 못한 배경/맥락을 보충
- 출처/수치를 본문에 자연스럽게 포함
- 이미지 삽입 위치 표시: `[이미지: 설명]`

## 3. 브런치 (Brunch)

### 용도
브런치스토리 — 에세이/칼럼형 글

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | 에세이, 사색적, 개인 관점 강조 |
| 구조 | 제목 → 도입(경험/관찰) → 전개 → 인사이트 → 여운 |

### 구조 상세
```
[제목] 문학적/감성적 표현 (호기심 유발)
[도입] 개인 경험이나 관찰에서 시작 (3-4문장)
[전개] 주제를 깊이 있게 풀어가는 서사 (쇼츠 핵심을 '이야기'로)
[인사이트] 독자에게 전하고 싶은 한 가지 메시지
[여운] 질문 또는 열린 결말로 마무리
```

### 작성 규칙
- 블로그와 달리 **개인 시점(1인칭)** 활용
- "나는 ~라고 생각한다", "~를 보면서 느낀 건" 등
- SEO보다 **읽는 맛**에 집중
- 데이터를 직접 나열하지 않고 이야기 속에 녹여내기
- 문단 사이 호흡 (한 문단 3-4문장)

## 4. 롱폼 (Long-form) — 주간 종합

### 용도
유튜브 롱폼 영상 대본 / 뉴스레터 / 심층 분석 콘텐츠

### 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 5,000-8,000자 |
| 영상 길이 | 10-15분 |
| 톤 | 분석적, 통찰력 있는, 전문가 시점 |
| 주기 | 주 1회 (7일치 쇼츠 기반) |
| 구조 | 인트로 → 주간 요약 → 심층 비교 분석 → 인사이트 → 전망 → CTA |

### 구조 상세
```
[인트로] 이번 주 핵심 흐름 요약 (훅 포함)
[주간 요약] 7일간 다룬 주제 브리핑 (각 1-2문장)
[비교 분석] 같은 카테고리 내 주제들의 공통점과 차이점
  - 어떤 트렌드가 보이는가?
  - 서로 어떻게 연결되는가?
  - 어떤 변화가 감지되는가?
[심층 인사이트] 개별 쇼츠에서는 볼 수 없었던 메타 관점
[전망] 다음 주/앞으로의 방향 예측
[CTA] 구독, 알림 설정, 댓글 유도
```

### 작성 규칙
- 7일치 쇼츠 대본을 모두 입력으로 받음
- 단순 나열이 아닌 **관통하는 인사이트** 도출
- "이번 주 AI 분야에서 공통적으로 보이는 흐름은..."
- 각 쇼츠를 참조할 때 날짜/제목 명시
- 차트/비교표 삽입 위치 표시: `[차트: 설명]`

---

## 포맷 간 관계도

```
[매일]  쇼츠 ──→ 블로그 (같은 주제, 정보 확장)
          │
          └──→ 브런치 (같은 주제, 에세이 전환)

[주간]  쇼츠 7개 ──→ 롱폼 (종합 분석)
```

## 포맷별 핵심 차별점 요약

| | 쇼츠 | 블로그 | 브런치 | 롱폼 |
|---|---|---|---|---|
| **목적** | 임팩트 | 정보 전달 | 공감/사색 | 심층 분석 |
| **시점** | 3인칭/객관 | 3인칭/객관 | 1인칭/주관 | 전문가 시점 |
| **구조** | 훅→본론→CTA | H2 섹션형 | 서사형 | 비교분석형 |
| **독자 행동** | 영상 시청 | 검색→읽기 | 구독→읽기 | 깊이 몰입 |
| **SEO** | 해시태그 | 키워드 최적화 | 낮음 | 중간 |
