# Vrew(브루) 영상 편집 — 수동 프로세스

## 역할
- 대본 + 이미지 조합으로 최종 영상 생성 (파이프라인 [8] 단계)

## 프로세스 설명

Vrew 단계는 별도의 AI 프롬프트 없이 수동으로 진행된다.

### 입력
1. **Claude 대본** — S00-S24 25슬라이드 스크립트 (`claude/01-shorts-script.md` 기준)
2. **GenSpark 이미지** — 슬라이드별 이미지 25장

### 작업 흐름
1. Vrew에 대본 텍스트 입력 (TTS 나레이션 생성)
2. S00-S24 슬라이드별 이미지 배치
3. 45초 지점(S12-15) 음악 반전 포인트 설정
4. 나레이션 타이밍과 이미지 전환 동기화
5. 최종 영상 렌더링

### 출력
- 90초 내외 쇼츠 영상 (세로 9:16)

### 주의사항
- 대본-이미지 1:1 매칭 확인
- 45초 피봇 포인트에서 음악 전환이 서사 반전과 동기화되는지 확인
- 90초 이내 분량 준수
