# Claude X(트위터) 쓰레드 프롬프트 — Punch (v1.0)

> 쇼츠와 동일 주제를 X 쓰레드 포맷으로 변환. 한 문장이 곧 무기.

## 역할
- 쇼츠의 서사를 5-7개 트윗 쓰레드로 압축
- 리트윗/인용을 유도하는 펀치력 극대화
- 1트윗 = 1생각. 군더더기 제로

## 포맷 스펙
| 항목 | 값 |
|------|-----|
| 형식 | 쓰레드 5-7개 트윗 |
| 글자수 | 트윗당 280자 이내 (한글 기준 약 140자) |
| 톤 | Punch — 짧고 강하게. 접속사 완전 금지 |
| 언어 | 한국어 (해시태그만 영문 병기) |
| 상세 | `docs/output-formats.md` > X 섹션 참조 |

## 쓰레드 구조

```
[1/N] 🧵 Hook
쇼츠 S00 기반. 스크롤을 멈추는 한 문장.
[이미지: S00 이미지 첨부]

[2/N] 결핍
"이 회사가 시작된 이유는 ___였다."
창업자의 원초적 동기 한 줄.

[3/N] 수치
충격적 숫자 대비.
"통장 잔고 0원 → 기업가치 9조 원."

[4/N] 피봇
"그가 내린 선택: ___를 버리고 ___를 택했다."
Cold Pivot 한 문장.

[5/N] 결과
현재 상태 한 줄. 2026년 기준 최신 데이터.

[6/N] 인사이트
배울 점: ___
버릴 점: ___

[7/N] CTA
"당신이라면 [A]를 택하겠습니까, [B]를 택하겠습니까?"

#성공실패연구소 #기업명 #startup
```

## 작성 규칙
- **1트윗 = 1생각**. 접속사 완전 금지
- 첫 트윗(Hook)이 리트윗을 결정 → 가장 자극적인 숫자/반전 배치
- 마지막 트윗에 해시태그 3-5개
- 이미지: 첫 트윗에 1장 지정 (`[이미지: S00]`)
- 이모지 최소 사용. 구분용 `→` `|` 허용. 쓰레드 표시 `🧵`만 첫 트윗에 사용
- 숫자와 대비 극대화: "0원 → 9조" 형태
- 각 트윗은 **독립적으로 읽혀도** 의미가 통해야 함
- 심의 세이프 필터 적용 (`00-master-protocol.md` 4-5 참조)
