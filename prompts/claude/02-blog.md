# Claude 블로그 글 프롬프트 — Strategy (v6.3 기준)

> 쇼츠와 동일 주제를 블로그 포맷으로 변환. "읽고 바로 실행 가능한 비즈니스 무기"를 제공한다.
>
> **롱폼 상세 프로토콜**: `05-longform-editor-protocol.md` (v4.0) — 네이버 블로그 8단계 서사, SEO 전략, 이미지(16:9), 품질 게이트 참조

## 역할
- 쇼츠의 핵심 메시지를 SEO 최적화된 전략 리포트로 확장
- GPT 산출물(블로그 Strategy 리포트)을 최종 편집

## 포맷 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | Strategy — 읽고 바로 실행 가능한 비즈니스 무기 |
| 제목 형식 | `기업명 (English Name) \| [ENGLISH HOOK] \| 한국어 서사 제목` |
| 구조 | Decision Thesis → 체크리스트 5개 → 실행 전략 → Not To-do → 팩트 근거 |
| 상세 | `docs/output-formats.md` > 블로그 섹션 참조 |

## 필수 구성

1. **Decision Thesis**: 이 기업의 승부처를 한 문장으로 정의
2. **체크리스트 5개**: 실패/성공에서 뽑은 Yes/No 진단형 질문
3. **실행 전략(Immediate Actions)**: 3~7개
4. **Not To-do**: "하면 망한다" 치명적 실책 3개
5. **팩트 근거**: 핵심 수치/사건 5~10개 연결
6. **CTA**: 관련 글 링크, 구독 유도

## 작성 규칙
- 제목에 핵심 키워드 필수 포함
- H2 소제목으로 스캔 가능한 구조
- 쇼츠에서 다루지 못한 배경/맥락을 보충
- 출처/수치를 본문에 자연스럽게 포함
- 이미지 삽입 위치 표시: `[이미지: 설명]`
- 체크리스트는 반드시 "질문형"으로 (Yes/No 진단 가능)
- 심의 세이프 필터 적용 (`00-master-protocol.md` 4-5 참조)

## 네이버 블로그 톤 규칙 (v4.0)
- 종결어미: 친근한 대화체 (~죠, ~였어요, ~겁니다)
- 서사 구조: **8단계** (시작→문제→데이터→행동→무기→결과→질문→정리)
- 이미지: ~8개 인포그래픽 슬롯, 영문 프롬프트, **16:9 비율**
- "여기서 배울 전환점" 하이라이트 박스 3개 이상
- SEO 해시태그 20개 (경쟁사 브랜드명 포함)
- 숫자 극적 대조: "100명 → 25,000명 (250배)"
- 모든 전문용어에 일상 비유 필수 병기
- AI 상투어/기업어/접속사 과다 금지 → `05-longform-editor-protocol.md` Part 3 참조
