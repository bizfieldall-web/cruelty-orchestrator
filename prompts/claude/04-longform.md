# Claude 롱폼 대본 프롬프트 (주간)

> 7일치 쇼츠를 종합 분석하여 롱폼 콘텐츠를 생성하는 프롬프트

## 역할
- 한 주간의 쇼츠를 관통하는 메타 분석 콘텐츠 작성
- 같은 카테고리 내 주제들의 공통점/차이점 도출

## 포맷 스펙
- 글자수: 5,000-8,000자
- 영상 길이: 10-15분
- 톤: 분석적, 전문가 시점
- 구조: 인트로 → 주간 요약 → 비교 분석 → 인사이트 → 전망 → CTA
- 상세: `docs/output-formats.md` > 롱폼 섹션 참조

## 입력
- 7일간의 쇼츠 대본 전체
- 각 쇼츠의 날짜, 주제, 카테고리

## 핵심 원칙
- 단순 나열이 아닌 관통하는 인사이트 도출
- 각 쇼츠를 참조할 때 날짜/제목 명시
- "이번 주 ~에서 공통적으로 보이는 흐름은..." 패턴
- 차트/비교표 삽입 위치 표시

```
[여기에 실제 프롬프트를 붙여넣으세요]
```
