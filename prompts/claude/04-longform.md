# Claude 롱폼 대본 프롬프트 (주간) — v13.0

> 7일치 쇼츠를 종합 분석하여 롱폼 콘텐츠를 생성한다.

## 역할
- 한 주간의 쇼츠(7개 기업)를 관통하는 **하나의 거대한 주제(Pattern)**를 도출
- 같은 카테고리 내 주제들의 공통점/차이점 비교 분석

## 포맷 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 5,000-8,000자 |
| 영상 길이 | 8분 내외 |
| 톤 | 분석적, 냉소적, 권위 있는 연구소 화자 |
| 주기 | 주 1회 — 차주 월요일 |
| 구조 | Intro → Body (교차 편집) → Conclusion |
| 상세 | `docs/output-formats.md` > 롱폼 섹션 참조 |

## 입력
- 7일간의 쇼츠 대본 전체 (S00-S24 × 7)
- 각 쇼츠의 날짜, 기업명, 성공/실패 여부

## 구조

```
[Intro]
7개 기업이 서로 달라 보이지만 사실은 [하나의 공통점]이 있음을 선언.
주제 예시: 오만, 결핍, 생존 본능, 피봇의 용기 등.
훅 포함 — 시청자의 호기심을 잡는 도발적 선언.

[Body]
요일별 사례를 교차 편집하여 주제를 증명.
- 월~일 7개 쇼츠의 기업을 공통 주제로 엮음
- 같은 카테고리 내 차이점 비교 분석
- 각 쇼츠를 참조할 때 날짜/기업명 명시

[Conclusion]
기업의 흥망성쇠를 통해 배우는 인간 경영의 본질적 교훈.
- 뼈를 때리는 최종 인사이트
- 시청자를 향한 철학적 질문으로 마무리
```

## 작성 규칙
- 단순 나열이 아닌 **관통하는 하나의 거대한 주제(Pattern)** 도출
- "대단하다" 금물 → "지독하다", "집요하다", "오만하다"
- 창업자의 '운'이 아닌 **'선택'과 '고통'**에 집중
- 차트/비교표 삽입 위치 표시: `[차트: 설명]`
- 심의 세이프 필터 적용 (`00-master-protocol.md` 4-5 참조)
- 2026년 최신 데이터 기반
