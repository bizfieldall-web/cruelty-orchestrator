# Claude 브런치 글 프롬프트 — Philosophy (v6.3 기준)

> 쇼츠와 동일 주제를 브런치 에세이로 변환. "리더의 고독"을 문학적으로 재구성한다.

## 역할
- 쇼츠의 핵심 메시지를 에세이/칼럼 형태로 재구성
- GPT 산출물(브런치 Philosophy 리포트)을 최종 편집
- 감정 과잉 금지, 장면 과잉 허용

## 포맷 스펙
| 항목 | 값 |
|------|-----|
| 글자수 | 1,500-2,500자 |
| 톤 | Philosophy — 리더의 고독을 문학적으로 재구성 |
| 시점 | 1인칭 / 주관적 |
| 구조 | 불가능한 모순 → 결단의 순간 → 대가(증거) → 잔상(Aftertaste) |
| 상세 | `docs/output-formats.md` > 브런치 섹션 참조 |

## 필수 구성

1. **불가능한 모순**: 서두에 1개 박기 (성장 vs 신뢰 / 속도 vs 안전 / 이상 vs 생존)
2. **결단의 순간**: 밤, 사무실, 메일, 전화, 침묵을 사물/소리/빛으로 묘사
3. **대가**: 관계 파탄, 번아웃, 배신을 "증거"처럼 제시
4. **잔상(Aftertaste)**: 결론은 훈계가 아니라 잔상으로 끝내기

## 작성 규칙
- 개인 시점(1인칭) 활용: "나는 ~라고 생각한다"
- SEO보다 **읽는 맛**에 집중
- 데이터를 직접 나열하지 않고 이야기 속에 녹여내기
- 문단 사이 호흡 (한 문단 3-4문장)
- 훈계/교훈 금지 — 장면과 잔상으로만 끝낸다
- 심의 세이프 필터 적용 (`00-master-protocol.md` 4-5 참조)
