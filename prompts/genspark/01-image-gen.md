# GenSpark 이미지 생성 — 수동 프로세스

## 역할
- 나노바나나 프롬프트 기반 이미지 생성 (파이프라인 [7] 단계)

## 프로세스 설명

GenSpark 단계는 별도의 AI 프롬프트 없이 수동으로 진행된다.

### 입력
- Gemini 나노바나나 단계(`gemini/04-nanobanana.md`)에서 출력된 **S00-S24 슬라이드별 이미지 프롬프트 25개**

### 작업 흐름
1. Gemini가 생성한 영문 이미지 프롬프트를 GenSpark에 입력
2. GenSpark가 이미지 생성
3. 생성된 이미지를 슬라이드 번호에 맞춰 정리

### 출력
- S00-S24에 1:1 대응하는 이미지 25장

### 주의사항
- 실존 인물 얼굴 직접 묘사 금지 (실루엣, 뒷모습, 상징물로 대체)
- 브랜드 로고 직접 생성 금지 (유사 형태나 상징으로 대체)
- 일관된 색감/스타일 톤 유지
